# zPlayer Badge Library

预览：https://zhaoyunxiong.github.io/zPlayer-Badges/

徽章库：https://zhaoyunxiong.github.io/zPlayer-Badges/badges.json

在 zPlayer 的「徽章库 → 从链接导入」中粘贴徽章库地址。

共 167 枚徽章，17 个分组：分辨率、片源、封装格式、视频技术、视频编码、音频技术、音频编码、声道、Dolby Vision Profile、位深、音频位深、采样率、帧率、字幕类型、字幕格式、其他、制作组。

自绘 SVG 可通过 `node scripts/generate-badge-assets.mjs` 重新生成。
